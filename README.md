# 🖥️ Screen Translator (Экранный переводчик)

Легковесное десктопное приложение для быстрого захвата области экрана, распознавания текста на ней с помощью нейросети (**EasyOCR**) и мгновенного перевода на русский язык. Программа работает в фоновом режиме в системном трее и активируется по удобной глобальной горячей клавише.

---

##  Особенности проекта
- **Выделение области в реальном времени:** Полупрозрачный оверлей (как в «Ножницах»), позволяющий выделить любой фрагмент экрана (текст из игр, приложений, картинок или видео).
- **Многопоточная архитектура:** Интерфейс на `Tkinter` никогда не зависает — вся тяжелая работа (скриншот, OCR и сетевой перевод) вынесена в фоновые потоки с безопасной передачей данных через `root.after()`.
- **Ленивая загрузка (Lazy Loading):** Нейросеть `EasyOCR` инициализируется только при первом вызове перевода, благодаря чему приложение стартует мгновенно.
- **Работа из системного трея:** Программа не захватывает панель задач, сворачивается в трей и управляется через иконку (`pystray`).
- **Без прав администратора:** Используется библиотека `pynput` для глобальных горячих клавиш, что позволяет запускать приложение без запроса прав суперпользователя в Windows.

---

##  Стек технологий
* **Язык:** Python 3.x
* **Интерфейс & GUI:** `Tkinter` (встроенный GUI), `Pillow` (работа с иконками и изображениями)
* **Захват экрана:** `mss` (сверхбыстрый скриншот по координатам в память)
* **Распознавание текста (OCR):** `EasyOCR` (поддержка английского и русского языков)
* **Перевод:** `googletrans` (Google Translate API)
* **Системный трей и хуки:** `pystray`, `pynput`

##  Установка и запуск (Для разработчиков)

Если вы хотите запустить проект локально из исходного кода:

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://github.com/GrimVanil/screen-translator.git](https://github.com/GrimVanil/screen-translator.git)
   cd screen-translator


2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   venv\Scripts\activate  

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt

4. **Запустите приложение:**
   ```bash
   python main.py

⌨️ Управление
Shift + U (или Shift + Г) — Сделать скриншот и перевести выделенную область.

Системный трей — Нажмите правой кнопкой мыши по иконке в трее и выберите «Выход» для закрытия программы.
